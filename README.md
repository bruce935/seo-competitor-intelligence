# SEO Competitor Intelligence

An Agent Skill for turning public competitor-web evidence into actionable SEO intelligence.

## V2 features
- architecture analysis
- topic/keyword intelligence
- search-intent analysis
- competitor strengths/weaknesses
- content-gap analysis
- opportunity scoring
- content recommendations
- 30/60/90-day roadmap
- evaluation cases

## Product strategy
Free edition: architecture, topic and basic gap analysis.
Pro edition: live SERP research, multi-competitor analysis, richer opportunity scoring,
content briefs and agency reporting.
