# V2 Scripts

Planned deterministic utilities:

- `sitemap_parser.py` — parse public XML sitemaps
- `extract_metadata.py` — extract title, headings, canonical, and links

V2 intentionally does not include automated crawling or search APIs. Add those only
with explicit rate limits, robots/terms consideration, and a documented data source.

Never add credential collection, authentication bypass, or unauthorized crawling.
