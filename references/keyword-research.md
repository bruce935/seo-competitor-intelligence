# Keyword Research

## Sources
Extract themes from titles, H1/H2s, URLs, navigation, categories, anchors, FAQs,
comparison pages, product/service terminology, and recurring topical language.

## Cluster types
- Core topic
- Supporting subtopics
- Commercial modifiers
- Informational modifiers
- Comparison/alternative terms
- Audience/location modifiers

## Integrity
Do not invent search volume, CPC, difficulty, rankings, or traffic. If an external
data source is used, record the source and date.
