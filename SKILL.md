# SEO Competitor Intelligence

Turn public competitor-web evidence into an actionable SEO intelligence report.

## Operating principles

1. Separate **Observed**, **Inferred**, and **Recommended** findings.
2. Never fabricate rankings, traffic, backlinks, search volume, CPC, or difficulty.
3. Prefer current public evidence when available.
4. Load references only when needed.
5. If quantitative SEO data is unavailable, use qualitative signals and say so.

## Workflow

### 1. Scope
Identify competitor URL/domain, website type, business model, market, language,
audience, products/services, and user goals. Proceed with available information.

### 2. Research
Inspect public pages and, when available, public sitemap/robots information.
Capture titles, headings, URLs, page types, navigation, topic terminology,
comparison pages, FAQs, and internal-link patterns.

### 3. Architecture
Map major page types and topic clusters. Identify whether the site is organized
around products, categories, audiences, locations, use cases, or search queries.

### 4. Topic and keyword intelligence
Extract recurring themes from visible content, URLs, titles, headings, navigation,
anchors, FAQs, comparisons, and product/service language. Cluster related terms.
Classify intent as informational, commercial investigation, transactional,
navigational, or mixed.

### 5. SERP research
If live search is available, inspect current result pages for important queries.
Record dominant intent, recurring page types, content angles, competitor presence,
and visible SERP features. State the observation date. Never claim an exact rank
unless it was actually observed.

### 6. Strengths and weaknesses
Assess topical breadth/depth, commercial coverage, comparison content, internal
linking, freshness, content architecture, and scalable page patterns. Only report
weaknesses supported by evidence.

### 7. Gap analysis
Find topics/pages that competitors cover poorly or that appear underserved.
Prioritize using business relevance, intent, competitive gap, strategic value,
and execution effort.

### 8. Opportunity scoring
Use `references/scoring-model.md`. Prefer qualitative labels when quantitative
data is unavailable.

### 9. Recommendations
Turn opportunities into concrete assets: landing pages, category pages,
comparison/alternative pages, guides, tutorials, case studies, FAQs, glossary
pages, and supporting articles. Include title/topic, intent, audience, page type,
internal-link opportunities, and priority.

### 10. Roadmap
Create 0–30, 31–60, and 61–90 day phases. Start with high-value, feasible,
commercial opportunities; then expand clusters, supporting content, internal links,
authority, and refreshes.

## Multiple competitors

Analyze each independently, then compare:
- shared topics
- unique competitor coverage
- shared gaps
- underserved opportunities
- competitor advantages
- user advantages

Do not assume the most common competitor topic is automatically the best opportunity.
